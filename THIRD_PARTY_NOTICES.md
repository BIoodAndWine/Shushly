## 2. Upstream DNS Resolvers & Blocklists

Shushly routes DNS queries to publicly accessible, encrypted DNS-over-HTTPS (DoH) services. Shushly does not host or operate its own DNS servers.

| Resolver / List | Maintainer | Upstream Project |
|---|---|---|
| **Control D Free DNS** | Control D Inc. | [https://controld.com/free-dns](https://controld.com/free-dns) |
| **OISD Blocklist** | Stephan van der Meer (OISD) | [https://oisd.nl/](https://oisd.nl/) |
| **HaGeZi Blocklists** | HaGeZi | [https://github.com/hagezi/dns-blocklists](https://github.com/hagezi/dns-blocklists) |
| **AdGuard DNS** | AdGuard Software Ltd. | [https://adguard-dns.io/](https://adguard-dns.io/) |
| **BlahDNS** | BlahDNS Community | [https://blahdns.com/](https://blahdns.com/) |
| **dnsforge.de** | admin@dnsforge.de | [https://dnsforge.de/](https://dnsforge.de/) |
| **LibreDNS** | LibreOps | [https://libredns.gr/](https://libredns.gr/) |
| **DNS4EU** | Whalebone / EU Consortium | [https://www.joindns4.eu/](https://www.joindns4.eu/) |
